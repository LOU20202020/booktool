# 书籍制作工具 · 使用说明

把 PDF 排成能折、能订、能裁的书。**全程在你自己的电脑上运行，文件不上传。**

---

## 一、打开（免安装）

1. 把 zip **整个解压**到任意位置（桌面、D 盘、U 盘都行，不需要管理员权限）。
2. 进 `书籍制作工具` 文件夹，双击 **书籍制作工具.exe**。
3. 想放桌面：右键这个 exe → 发送到 → 桌面快捷方式。

第一次打开如果弹出蓝色的“Windows 已保护你的电脑”：
点 **更多信息 → 仍要运行**。这是因为程序没买数字签名证书，不是病毒。

**不要**把 exe 单独拖出来——`_internal` 是运行库，必须跟它待在同一个文件夹。
换电脑就把整个文件夹拷过去，照样能跑。

**删除**：直接删掉整个文件夹即可，不写注册表、不留残留。

---

## 二、三步做一本骑马钉小册子

1. **拖 PDF 进来**——把文件直接拖到窗口里，或点左上「选择」。
2. **左侧选参数**——一般只要动两个：
   - 装订方式：薄本选「骑马钉」，厚本选「胶装分册」。
   - 每册页数：`20` 就是每册 5 张纸；填 4 的倍数，不是的话程序会自动补空白页。
3. **点右下红色按钮**——几秒出结果，点「打开文件」直接看。

结果默认存在**原 PDF 旁边**，文件名后面加 `-小册子`。重名不会覆盖，会自动变成 `-2`、`-3`。

---

## 三、打印

软件已经能直接打印了：生成结果后点底部的 **「打印」**，会带着这份成品跳到「打印」页，
双面、短边翻转、A4、100% 都自动设好，份数/纸张沿用上次，确认一下就能打。

**打印对话框里还能做三件事**

- **只补印几页**：把「打印面数」切成“部分”，按**面（页）**填，例如 `5-10,12`；下方「将要打印」会列出每一面的缩略图，标着面号和正/背，打之前就能确认到底打哪几张。
- **打原稿**：「打印内容」切到“原稿（未拼版）”，直接把源 PDF 打出来，不用先生成成品。
- **看缩略图**：左上角显示第 1 张纸的实际样子，下方列出要打的每一面。

第一次打建议**保持勾选“只印 1 张样张”**，先验一张方向：

- 正面：左 = 本册最后一页，右 = 第 1 页
- 反面：左 = 第 2 页，右 = 倒数第 2 页

对得上，再取消勾选打整本。

**打印机只能单面怎么办？**
打印对话框里把双面选成 **「单面打印机 · 手动双面」**，软件会自动分两遍：
先打正面 → 弹窗提示你把整叠纸原样取出、**不要打乱顺序**、翻面放回 → 再打背面。

翻面方向看提示：小册子是横向的，**上下翻**（沿短边，像翻日历）；四堆叠/加页码是竖向的，**左右翻**（沿长边，像合书）。
第一次务必勾着“只印第 1 张”，确认背面没套歪再整本打。

如果你想自己用阅读器/系统打印，按下面设：

## 三之二、自己设打印机时（这一步最容易出错）

| 设置 | 选什么 |
|---|---|
| 双面 | 打开 |
| 翻页方式 | **短边翻转**（不是长边） |
| 缩放 | **100%**，不要选“适合页面” |
| 纸张 | A4 |

打印前**先打第一张验一下**：

- 正面：左 = 本册最后一页，右 = 第 1 页
- 反面：左 = 第 2 页，右 = 倒数第 2 页

对得上就整本打；对不上就是“短边翻转”选错了。

打完沿**中线对折**，把左半边往后翻，书脊在左边，订两针即可。

## 四、十二个工具分别干什么

| 工具 | 什么时候用 |
|---|---|
| **书架** | 做整本书就从这里开始：把一个文件夹拖进书架（文件夹名 = 系列名），里面的 PDF 按卷号自动排好。每本书做到第几步、有哪些产物、定稿是哪份，一眼能看到 |
| **生产** | 点开一本书就是七道工序的节点图：①导入 → ②分割 → ③封面 → ④页码 → ⑤排版 → ⑥打印 → ⑦定稿。绿=已完成、橙=上游改过要重跑、灰=还没做；点节点看说明和产物，右边「打开这一步的工具」直接跳 |
| **分割** | 前 N 页析出成**封面素材**、末尾 M 页当**封底素材**、其余留成**正文**，三个文件落在原稿旁边；切好的素材能一键送进「封面」的图槽 |
| **转换** | MOBI / AZW3 / EPUB / TXT 等电子书转成 PDF，可选纸张、书型（文字书/漫画）、字体、字号、页边距。要用免费的 Calibre，没装时页面会直接告诉你缺什么、去哪装 |
| **小册子** | 最常用。A4 一张折成 A5 两页，骑马钉 / 厚书分册胶装。选 A6 还能一张 A4 出两份，中间横切 |
| **封面** | 有设计好的图就直接导入：封面图 / 书脊图 / 封底图分开选，三种放置方式（等比适应 / 等比填满 / 拉伸填满）。也可以不用图，用四套版式＋五套配色现做。**书脊厚度按实测填**（不再按页数估算），填 0 就不印书脊文字 |
| **四堆叠** | 一张 A4 排 8 页，切两刀成 4 叠，做 A6 小本最省纸 |
| **4合1** | 4 页缩到 1 张 A4，做讲义、资料汇编 |
| **合并** | 多个 PDF 合成一个，列表里可以拖动排序 |
| **分拆** | 一份 PDF 按页数或按份数切开，比如每 20 页一份 |
| **加页码** | 给现成 PDF 加页码：底部居中 / 外侧 / 顶部，可跳过封面、奇偶页镜像 |
| **打印** | 选任意 PDF（原稿或成品）直接送印：双面短边、100% 不缩放、按面选范围，单面机自动分两遍 |

**封面右栏太挤？** 封面页右上角的 **×** 一键收起右栏，画布立刻变宽；收起时右栏里的文字会临时清空
（封面只剩你导入的图），点右边缘竖排的「右侧栏」原样恢复。文件名太长也不怕，图槽会自动省略成「…」。

**小技巧**

- 右侧「纸张」里的缩略图点一下，中间就切到那一张；想看别的张不用重新生成。

- 一次要做好几本？小册子页点 **「批量：整个文件夹…」**，把同一个文件夹里的 PDF 按当前参数全部拼好。
- 换工具不用重新选文件，**选一次所有工具通用**。
- 想从第 5 页开始排（前 4 页是封面不参与）？用「从第几页开始」，下方可以翻原稿挑。
- 结果想放到别处：底部 **「输出：原文件夹」** 可以改。
- 点错了想停：处理过程中点 **取消**，已生成的文件不会删。
- 打完一本，书架里会记着「打印 N 次 · 共 X 张纸 · 最近 时间」，生产线第⑥步也变完成；
  只打一张样张也会留痕，但不算这一步做完。

## 五、常见问题

**页码对不上 / 印出来是倒的？**
九成是打印机选了“长边翻转”。改回**短边翻转**再试。

**中间多出空白页？**
正常。页数不是 4 的倍数时程序会补空白，保证每一张纸正反面对得上。

**PDF 打不开，提示有密码？**
先用别的软件（如 PDF24、Adobe）去掉打开密码，再导入。

**书脊太窄，字挤成一团？**
封面页把书脊字号调小，或勾上「竖排」。

**结果在哪？**
默认在原 PDF 旁边；按钮上会写着「输出：原文件夹」。

**软件报错了？**
弹窗里给了日志路径：`%LOCALAPPDATA%\XPlus\BookTool\logs\app.log`，把它发给作者即可。
